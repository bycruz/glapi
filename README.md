# glapi

Cross-platform low level OpenGL bindings for LuaJIT.

> [!NOTE]
> This is very rough around the edges as I prioritize work on [hood](https://github.com/codebycruz/hood) and [vkapi](https://github.com/codebycruz/vkapi) instead.

## Installation

This is intended to be consumed with the [lpm](https://github.com/codebycruz/lpm) package manager.

```bash
lpm add --git https://github.com/codebycruz/hood
```
