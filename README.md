# glapi

Cross-platform low level OpenGL bindings for LuaJIT.

> [!NOTE]
> This is very rough around the edges as I prioritize work on [hood](https://github.com/bycruz/hood) and [vkapi](https://github.com/bycruz/vkapi) instead.

## Installation

Use this package with the [lde](https://lde.sh/) package manager.

```bash
lde add --git https://github.com/bycruz/glapi
```
